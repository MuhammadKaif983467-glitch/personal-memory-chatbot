## Pinned Project Description

> **Personal Memory Chatbot** — A full-stack application that learns about people from their conversation history. Imports chat logs (WhatsApp, Telegram, Instagram, Facebook, JSON, CSV, TXT, ZIP), extracts facts and preferences with confidence scoring, versions memory corrections, and answers questions grounded in retrieved evidence. Built with FastAPI, React, SQLite, and OpenRouter.
